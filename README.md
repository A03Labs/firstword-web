# FirstWord

The FirstWord landing page and privacy policy site, built with [Next.js](https://nextjs.org).

## Getting Started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

The landing page lives in `src/app/page.tsx`, and the policy lives in `src/app/privacy/page.tsx`.
Tailwind utilities provide the landing-page styling; shared font and theme tokens live in
`src/app/globals.css`.

## Commands

```bash
npm run lint
npm run build
npm run start
```
